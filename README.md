# NEURA

Hackathon project analysing SEM images of Si–graphite battery anodes (Polaron dataset).

| Folder | What it does |
|---|---|
| [`si_graphite_bse/`](si_graphite_bse/) | Detects silicon, graphite and pore in BSE images and computes amount, size, distribution and composition KPIs per image and per batch. |
